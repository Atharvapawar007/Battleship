# ⚓ Battleship

A modern implementation of the classic **Battleship** strategy game built with **JavaScript**, **Webpack**, **HTML**, and **CSS** as part of **The Odin Project's JavaScript curriculum**.

This project focuses on writing modular JavaScript, separating game logic from the UI, and practicing Test Driven Development (TDD) with Jest.

---

## 🎮 Preview

A two-player local Battleship game where each player:

- Enters their name.
- Places all five ships on a 10×10 board.
- Takes turns attacking the opponent's fleet.
- Wins by sinking every enemy ship.

## 🧠 How the Game Works

### 1. Player Creation

Players enter their names before the game begins.

### 2. Ship Placement

Each player places the following fleet:

| Ship             | Length |
| ---------------- | ------ |
| Aircraft Carrier | 5      |
| Battleship       | 4      |
| Cruiser          | 3      |
| Submarine        | 3      |
| Destroyer        | 2      |

For every ship:

- Ship name and length are displayed automatically.
- Player chooses:

    - Starting row
    - Starting column
    - Orientation (Horizontal / Vertical)

Invalid placements (out of bounds or overlapping ships) show an error modal.

### 3. Gameplay

Players alternate turns attacking the opponent's board.

Each attack results in:

- 💥 Hit
- 🌊 Miss
- ❌ Error if an already attacked cell is selected.

### 4. Victory

The first player to sink every enemy ship wins.

A winner modal displays the winning player's name.

## 🏗️ Architecture

The project follows a modular design.

### `Ship.js`

Responsible for:

- Ship length.
- Tracking hits.
- Determining whether a ship has sunk.

### `Gameboard.js`

Responsible for:

- Creating a 10×10 board.
- Validating ship placement.
- Receiving attacks.
- Tracking hits, misses, and ships.
- Determining whether all ships have sunk.

### `Player.js`

Responsible for:

- Player information.
- Accessing the player's board.
- Checking win conditions.

### `GameController.js`

Responsible for:

- Managing turns.
- Processing attacks.
- Switching the active player.

### `DisplayController.js`

Responsible for:

- DOM manipulation.
- Rendering game boards.
- Handling forms and modals.
- Displaying errors and winner messages.
- Connecting UI interactions to game logic.

## 🚀 Getting Started

### Clone the repository

```bash
git clone git@github.com:Atharvapawar007/Battleship.git
cd Battleship
```

### Install dependencies

```bash
npm install
```

### Run development server

```bash
npm start
```

### Create a production build

```bash
npm run build
```

Webpack generates the production files inside the `dist/` directory.

---

## 🧪 Running Tests

Run all Jest tests:

```bash
npm test
```

Watch mode:

```bash
npm test -- --watch
```

## 🚢 Deployment (GitHub Pages)

The production build is deployed from the **`gh-pages`** branch.

### Build

```bash
npm run build
```

### Deploy updated build

```bash
git checkout gh-pages
cp -r dist/. .
git add .
git commit -m "deploy: production build"
git push origin gh-pages
git checkout main
```

GitHub Pages is configured to serve the `gh-pages` branch.
